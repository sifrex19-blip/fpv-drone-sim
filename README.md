# FPV Drone Sim

A lightweight FPV drone simulator for Windows and Linux, written in Rust with
[Bevy](https://bevyengine.org). Fly a race quad through gates or freestyle a
built-up map with a real controller — or keyboard — behind an OSD-style HUD.

## Features

- **Flight model** — Acro & Angle modes, Betaflight-style *Actual* rates
  (center sensitivity / max rate), stick expo and deadzone
- **Race Course** — 6-gate oval with lap timing, best-lap tracking and gate hints
- **Freestyle Park** — buildings, trees, runway, fog; battery model with
  voltage sag feeding the OSD
- **Launcher** — dark/purple UI with Home, Controller, Settings, Addons,
  Statistics and About pages
- **Controller Database** — 83 known radios, gamepads, joysticks and HOTAS rigs
  with product thumbnails, live input mapping, axis preview bars and stick
  calibration
- **Statistics** — flights, flight time, distance, top speed, crashes and laps,
  persisted on disk

## Controls

| Action | Keyboard | Gamepad |
|---|---|---|
| Pitch / Roll | `W` `S` / `A` `D` | Left stick |
| Yaw | `Q` `E` | Right stick |
| Throttle | `Space` / `Left Shift` | Right stick (mapped) |
| Arm / disarm | `Enter` | South (`A`) |
| Reset | `R` | Start |
| Toggle flight mode | `M` | West (`X`) |
| Toggle camera | `C` | East (`B`) |
| Pause menu | `Esc` | — |

Controllers can be remapped and calibrated on the **Controller** page; any
DirectInput/XInput/gamepad device Bevy detects works.

## Building

Requirements: [Rust](https://rustup.rs) (stable).

### Windows

```powershell
cargo build --release
./target/release/fpv-drone-sim.exe
```

### Linux

Needs the usual Bevy system dependencies:

```sh
sudo apt install libwayland-dev libxkbcommon-dev libasound2-dev
cargo build --release
```

### Cross-compiling Linux from Windows

```sh
# one-time: zig from https://ziglang.org/download + cargo install cargo-zigbuild
rustup target add x86_64-unknown-linux-gnu
cargo zigbuild --release --target x86_64-unknown-linux-gnu
```

The `assets/` directory must sit next to the executable (it is loaded from
disk at runtime, not embedded).
